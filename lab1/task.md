## Общая схема программы
Бесконечный цикл с пунктами меню (номера и формулировки уточнены в
семействе):
1. Создать структуру данных
2. Напечатать
3. Операция семейства
4. Алгоритм варианта
0. Выход
## Обязательства программы:
   * Никаких утечек памяти: каждая созданная через new[] структура
   освобождается через delete[]. После удаления указатель обнуляется (delete[]
   arr; arr = nullptr;).
   * Корректный ввод: при вводе чисел и меню проверяйте успешность std::cin
   (if (!(std::cin >> n)) { std::cin.clear(); ... }), не давайте программе упасть.
   * Устойчивость к пустой структуре: функции поиска и алгоритмы должны
   корректно работать с массивом длины 0 (возвращать false/безопасное
   значение), программа не должна падать.
   * Каждая операция выводит понятный результат (сам массив, длину,
   найденные значения).

## Меню семейства A:
```shell
1. Создать массив 2. Напечатать
3. Вставить элемент 4. Удалить элемент
5. Изменить размер 6. Печать
7. Алгоритм варианта 0. Выход
```

## Задания варианта (подробно)
Вариант 3. A · Массивы. Сортировка вставками по возрастанию; затем void
array_rotate_left(int* arr, size_t size, size_t k) — циклический сдвиг влево на k
(например, разворотом трёх отрезков).
Пример: массив {4, 2, 5, 1, 3} → сортировка {1, 2, 3, 4, 5} → сдвиг на k=2 → {3, 4,
5, 1, 2}. 

## Запрещены 
классы, конструкторы, семантика копирования/перемещения,
std::string, std::vector, std::array и умные указатели. Работа с памятью — только
вручную (new[] / delete[]), строки — только C-строки (char*, завершающий '\0').
